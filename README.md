## <samp>$ whoami</samp>

> **"문제를 만나면 일단 반갑습니다."** 🧐

백엔드가 본진인 개발자 **준수한쭌**입니다. Java · Spring · Kotlin으로 서버를 만들고, 요즘은 문제 해결 도구 자체를 만드는 재미에 빠져 있습니다.

- 🔭 **요즘 하는 것** — MCP 서버(`chacha-mcp`), 레거시 UI 수정 보조 도구(`assistant-ui`) 같은 AI 도구 만들기
- 🌱 **배우는 것** — Kotlin 기반 백엔드, Spring Batch(`killbatch`), TypeScript & React
- 🎥 **해본 것** — AWS Rekognition 영상 분석 백엔드, 실시간 영상 비전 분석 파이프라인
- ✍️ **기록하는 곳** — [준수한쭈니네](https://jjunii486.tistory.com/) <sub>(불친절한 쓸데없는 나만의 블뤄그 입니돠)</sub>
